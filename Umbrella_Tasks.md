# K5M — Umbrella Tasks

Ongoing, thematic workstreams — not date-bound like the Project Calendar, but the categories everything else gets tagged under. `#newtask` entries and Project Development Log entries (`260729_K5M_Project Calendar.xlsx`) get tagged with one of these, **always written in full — no abbreviations, ever, for the values themselves.** The only permitted shorthand is "UTSK," which Shagun may use as shorthand for the term "Umbrella Task" itself (the field/label), never as an abbreviation of a specific umbrella task.

## Weekly report

A fresh dated file each week, `YYMMDD_Weekly_Report.md` (same branch), one section per umbrella task above, summarizing that week's tagged developments and progress. Assembled collaboratively — Shagun gives input, Claude compiles — not an automated pivot off the other files.
