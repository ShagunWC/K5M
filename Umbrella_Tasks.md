## Weekly report

A fresh dated file each week, `YYMMDD_Weekly_Report.md` (same branch), one section per umbrella task above, summarizing that week's tagged developments and progress. Assembled collaboratively — Shagun gives input, Claude compiles — not an automated pivot off the other files.
