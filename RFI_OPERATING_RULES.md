# K5M — RFI Operating Rules

Standing rules for how the RFI Tracker (`260819_K5M_RFI_Tracker.xlsx` — Desktop until Shagun moves it to OneDrive herself, per Hard Rule 20) is numbered and filled in. See `Umbrella_Tasks.md` (`006_task-management-pm`) for the umbrella task list the tracker's "Origin" column draws from, and `CONTACT_SHEET.md` for who "To be followed up with" and "Owner" pull from.

## RFI numbering

Format: **`<Project Code>/<Zone Letter>/<Sequential Number>`** — e.g. `K5M/S/1`, `K5M/S/2`.

- **Project Code** — the project's codename (`K5M`).
- **Zone Letter** — matches the tracker's Zone column: `S` = Supplier, `C` = Client, `I` = Internal.
- **Sequential Number** — counts up within that zone only, not globally across the whole tracker. `K5M/S/1` and `K5M/C/1` can both exist at once; each zone keeps its own count. Never reused, same discipline as Task Numbers (Hard Rule 8).

## Email Chain Link

The column only ever holds a link to a **real, already-sent email** — never a placeholder or an internal prep email that led up to it.

- Leave it **blank** until the actual first outbound email on that RFI has been sent to whoever is meant to answer it.
- Once sent, link that email.
- When the RFI moves to **Acted On**, update the same cell to the reply's link instead of adding a new column — the tracker only ever needs one live link per RFI, but it's expected to change over the RFI's life.
