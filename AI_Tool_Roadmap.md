# AI Tool Roadmap

Long-term ambitions for turning this working method into a proper company tool, not scoped to any one project. Moved here (2026-07-30) rather than tracked as a normal project task, since these are ideas to develop over time rather than deliverables with a deadline.

## Open ideas

- **3D material model generator** — an agent that produces a 3D model showing material application on FF&E products, to align the client and all stakeholders visually rather than relying on flat material lists. First raised while working a live project, but the ambition is a reusable capability, not tied to any one project's build. (Not to be confused with a one-off 3D model built directly for a specific project's own briefing needs — that kind of thing stays a normal project task, not a roadmap item.)
